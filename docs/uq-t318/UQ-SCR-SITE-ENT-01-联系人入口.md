# UQ-SCR-SITE-ENT-01 企业档案 · 联系人入口（增量）

```yaml
编号: UQ-SCR-SITE-ENT-01
版本: 增量 v0.1-t327u
状态: 互审已无分歧 · 只补联系人入口 · 非 G2
关系: 不重写 N2 列表正文。联系人抽屉见 UQ-SCR-SITE-ENT-03
编码: N2 HOLD
```

N2 已冻的列表列、筛选、档案字段集合保持原样。本增量只加一条行操作，并写明档案保存与主联系人行的关系。

## 1. 行操作

企业列表 `/uq/site/enterprise/list` 的操作列增加「联系人」。

| 条件 | 表现 |
| --- | --- |
| 有 `site:enterprise:contact:list` | 显示按钮。点击后打开右侧抽屉，进入 `UQ-SCR-SITE-ENT-03`，带上该行企业 id |
| 无该权限 | 按钮不出现。接口 403 |

不新增一级菜单。不把独立联系人路由当作本屏的出口。本切片验收从这一行进入抽屉。

## 2. 字段

档案新建、编辑、查看的字段不增删。主联系人姓名、电话仍在表单上，列集合仍按冻结稿。

已有 `is_primary=1` 的未删除联系人时，保存档案里的姓名或电话，回写该联系人行的姓名、电话。角色、启停、主标记不因这次保存而改变。没有主联系人行时，只更新主档，不插入联系人。

## 3. 本屏不验收

- 联系人子表本身（在 ENT-03 抽屉验收）。
- 联系人删除。
- 独立联系人菜单页。
