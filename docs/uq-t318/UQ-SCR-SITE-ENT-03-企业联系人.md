本切片验收这只抽屉，不验收独立路由或一级菜单。路由 `/uq/site/enterprise/contact` 与菜单若保留，不进入本切片冒烟。

## 1. 容器

| 项 | 口径 |
| --- | --- |
| 打开方式 | ENT-01 某一行的「联系人」 |
| 容器 | 右抽屉，650px，子表在抽屉内滚动 |
| 标题 | 企业名称 · 联系人 |
| 只读眉区 | 信用代码、入驻状态。入驻状态不阻止打开，联系人接口不以入驻态做门禁 |
| 效果图 | 不新做 |

## 2. 打开结果（C2）

| 情况 | 界面 |
| --- | --- |
| 企业不存在、跨租户或已删除 | 统一业务错误。抽屉只显示「企业不存在或无权」。不展示表单，不当成空列表 |
| 企业有效，没有联系人 | 空列表，可点新建 |
| 无 `site:enterprise:contact:list` | 按钮不出现。直接请求为 403，文案不使用「企业不存在或无权」 |

## 3. 子列表

列：姓名、电话、角色、是否主联系人、启停、更新时间、操作。

操作只有查看、编辑。没有删除。

启停列展示启用或停用。停用行留在列表里。

分页跟随平台默认。主联系人排在前面，其余按修改时间倒序。

## 4. 新建与编辑

| 态 | 所属企业 | 其他字段 |
| --- | --- | --- |
| 新建 | 可选。从某行进入时默认该企业，允许改选 | 姓名必填。电话、角色、备注可空。角色空或五码。启停默认启用。主联系人默认否 |
| 编辑 | 只读。不可改挂接 | 可改姓名、电话、角色、启停、主标记、备注 |
| 查看 | 只读 | 全部只读 |

编辑请求若携带与库内不同的 `enterprise_id`，整单拒绝，抽屉留在原记录并展示后端文案。

点遮罩不关闭抽屉，与档案抽屉一致，避免未保存丢失。

角色下拉来自 `uq_enterprise_contact_role` 的五码，并允许空。种子不在本屏交付。非法码由接口拒绝，下拉不提供第五码以外的值。五码为 `LEGAL`、`FINANCE`、`IT`、`ADMIN`、`HR`。

## 5. 启停与主联系人

启停在编辑里直接改，无单独审批。停用主联系人后，企业列表上的联系人姓名、电话保持停用前的值。

取消主标记同样保留该快照。需要列表改显示别人时，把另一行设为主联系人。

本屏没有删除。删除以及「删尽主联系人则主档置空」不在本屏冒烟。该延后项与「取消或停用主联系人则保留快照」不是同一次测试。

## 6. 按钮权

| 按钮 | 权限 |
| --- | --- |
| 打开抽屉 | `site:enterprise:contact:list` |
| 查看 | `site:enterprise:contact:query` |
| 新建 | `site:enterprise:contact:add` |
| 编辑（含启停、主标记） | `site:enterprise:contact:edit` |

不放置删除按钮。无权限的按钮不渲染，接口 403。
